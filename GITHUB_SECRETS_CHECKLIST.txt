STEP-BY-STEP ADDING SECRETS TO GITHUB
════════════════════════════════════════════════════════════════════════════

For each secret:

1. Go to: https://github.com/fhbck87/church-website-fhbck/
           settings/secrets/actions

2. Click: "New repository secret" (top right)

3. Enter:
   Name:  [Exact secret name from this checklist]
   Value: [The actual secret value]

4. Click: "Add secret"

5. Repeat for each of the 16 required secrets

6. Wait 5 minutes for GitHub to recognize them
