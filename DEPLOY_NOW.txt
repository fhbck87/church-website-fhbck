🚀 DEPLOY TO HOSTINGER - 9 SIMPLE STEPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Total time: ~15-20 minutes

STEP 1️⃣  DNS CONFIGURATION
───────────────────────────────────────────────────────────────────────────
📍 Link: https://hpanel.hostinger.com/email/fhbckissimmee.org/connect-domain

Add these DNS records in Hostinger Control Panel:

  A Record:
  • Name: @ (root)
  • Type: A
  • Value: [Your VPS IP from Hostinger]
  
  CNAME Record:
  • Name: www
  • Type: CNAME
  • Value: fhbckissimmee.org

Wait 5-30 minutes for DNS propagation.


STEP 2️⃣  SSH INTO VPS
───────────────────────────────────────────────────────────────────────────
$ ssh root@[Your VPS IP]


STEP 3️⃣  INSTALL DOCKER (Copy-paste into terminal)
───────────────────────────────────────────────────────────────────────────
apt update && apt upgrade -y
curl -fsSL https://get.docker.com | sh
curl -L "https://github.com/docker/compose/releases/download/v2.24.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
chmod +x /usr/local/bin/docker-compose
docker --version
docker-compose --version


STEP 4️⃣  CLONE REPOSITORY
───────────────────────────────────────────────────────────────────────────
cd /opt
git clone https://github.com/fhbck87/church-website-fhbck.git church-website
cd church-website


STEP 5️⃣  RUN SETUP
───────────────────────────────────────────────────────────────────────────
sudo ./hostinger-deploy.sh setup

✓ Creates .env.production
✓ Generates secure database password
✓ Generates JWT secret


STEP 6️⃣  EDIT CONFIGURATION
───────────────────────────────────────────────────────────────────────────
nano .env.production

Key values to update:
  REACT_APP_API_URL=https://fhbckissimmee.org
  REACT_APP_ADMIN_EMAIL=admin@fhbckissimmee.org
  REACT_APP_ADMIN_PASSWORD=ChooseStrongPassword123!
  MAIL_HOST=smtp.gmail.com
  MAIL_USERNAME=your-email@gmail.com
  MAIL_PASSWORD=your-app-password

Save: Ctrl+X → Y → Enter


STEP 7️⃣  SETUP SSL CERTIFICATE
───────────────────────────────────────────────────────────────────────────
sudo ./hostinger-deploy.sh ssl

✓ Requests Let's Encrypt certificate
✓ Auto-renewal configured


STEP 8️⃣  COPY NGINX CONFIG
───────────────────────────────────────────────────────────────────────────
cp nginx/default.hostinger.conf nginx/default.conf


STEP 9️⃣  DEPLOY!
───────────────────────────────────────────────────────────────────────────
sudo ./hostinger-deploy.sh deploy

Wait for all services to start (5-10 minutes):
  ✓ postgres running (church-db)
  ✓ backend running (church-backend)
  ✓ frontend running (church-frontend)
  ✓ certbot running (church-certbot)

Verify:
  sudo ./hostinger-deploy.sh health

🆘 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ DNS not resolving?
→ Wait 30 minutes, check with: dig fhbckissimmee.org
→ Verify A record points to correct VPS IP

❌ SSL certificate error?
→ Run: sudo ./hostinger-deploy.sh ssl
→ Check: sudo docker logs church-certbot

❌ API not responding?
→ Check logs: sudo ./hostinger-deploy.sh logs
→ Verify CORS_ORIGINS in .env.production
→ Restart: sudo ./hostinger-deploy.sh restart backend

❌ Can't SSH to VPS?
→ Check SSH key permissions: chmod 600 ~/.ssh/id_rsa
→ Verify IP in Hostinger panel
