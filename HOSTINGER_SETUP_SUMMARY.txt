QUICK START (On Your Hostinger VPS)
================================================================================

1. SSH into VPS:
   $ ssh root@your-vps-ip

2. Install Docker & Docker Compose:
   $ apt update && apt upgrade -y
   $ curl -fsSL https://get.docker.com | sh
   $ sudo curl -L "https://github.com/docker/compose/releases/download/v2.24.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
   $ sudo chmod +x /usr/local/bin/docker-compose

3. Clone and setup:
   $ cd /opt
   $ git clone <your-repo-url> church-website
   $ cd church-website

4. Run deployment setup:
   $ sudo ./hostinger-deploy.sh setup

5. Edit configuration:
   $ nano .env.production
   [Update: REACT_APP_API_URL, MAIL settings, ADMIN credentials, CORS_ORIGINS]

6. Setup SSL certificates:
   $ sudo ./hostinger-deploy.sh ssl

7. Copy production nginx config:
   $ cp nginx/default.hostinger.conf nginx/default.conf

8. Deploy:
   $ sudo ./hostinger-deploy.sh deploy

9. Verify:
   $ sudo ./hostinger-deploy.sh health

REQUIRED CONFIGURATION
================================================================================

Before deploying, customize .env.production:

Domain:
  REACT_APP_API_URL=https://yourdomain.com
  CORS_ORIGINS=https://yourdomain.com,https://www.yourdomain.com

Admin Account (change password after login!):
  REACT_APP_ADMIN_EMAIL=admin@yourdomain.com
  REACT_APP_ADMIN_PASSWORD=ChangeMe123!
  REACT_APP_ADMIN_NAME=Administrator

Email (SendGrid/SMTP):
  MAIL_HOST=smtp.gmail.com
  MAIL_PORT=587
  MAIL_USERNAME=your-email@gmail.com
  MAIL_PASSWORD=your-app-password
  MAIL_NOTIFY_TO=admin@yourdomain.com

Optional (if using):
  REACT_APP_YOUTUBE_API_KEY=your-api-key
  REACT_APP_YOUTUBE_CHANNEL_ID=your-channel-id
  REACT_APP_STRIPE_PUBLISHABLE_KEY=pk_live_...
  STRIPE_SECRET_KEY=sk_live_...

Auto-generated (by setup script):
  DB_PASSWORD=<secure-password>
  JWT_SECRET=<secure-key>

Network:
  • Domain pointing to VPS IP

  • Outbound internet for Docker images and updates
